# Sai Sushrith — AI/ML & Software Engineering Student Portfolio

Architectural Swiss-style personal portfolio website for **Sai Sushrith**, built strictly adhering to the Google Stitch design specifications (`projects/17026510607991612204`) and inspired by the visual design of [`ingrassiadaniel.it`](https://ingrassiadaniel.it/).

## Technical Architecture

- **Stack**: Pure HTML5, CSS3, and Vanilla JavaScript (ES6+).
- **Zero Frameworks**: No React, Next.js, Vue, Tailwind, Bootstrap, jQuery, Three.js, or external JS runtime dependencies.
- **Generative Particle System**: Built with native HTML5 Canvas 2D, featuring all 8 stages from Anatomical Silhouette Bust to Convergent Vortex.
- **Responsiveness**: Responsive orthogonal grid system adapting cleanly across all viewports.
- **Accessibility**: Keyboard navigable skip links, visible focus states, ARIA roles, semantic landmarks, and full `prefers-reduced-motion` support.
