# Sai Sushrith — AI/ML & Software Engineer Portfolio

Architectural Swiss-style personal portfolio website for **Sai Sushrith**, built strictly adhering to the Google Stitch design specifications (`projects/17026510607991612204`) and inspired by the visual design of [`ingrassiadaniel.it`](https://ingrassiadaniel.it/).

## Technical Architecture

- **Stack**: Pure HTML5, CSS3, and Vanilla JavaScript (ES6+).
- **Zero Frameworks**: No React, Next.js, Vue, Tailwind, Bootstrap, jQuery, Three.js, or external JS runtime dependencies.
- **Generative Particle System**: Built with high-performance native HTML5 **Canvas 2D**, featuring:
  - **Stage 0**: Anatomical Humanoid Bust Silhouette with an interactive glowing celestial orb tracking cursor movement and repelling nearby particles.
  - **Stage 1**: Dynamic Dispersal into geometric architecture.
  - **Stage 2**: Undulating Riemannian wave manifold backdrop for Manifesto / About.
  - **Stage 3**: Concentric orbital gyroscope for Selected Projects exhibition.
  - **Stage 4**: Crystalline 3D cubic lattice matrix with connecting lines for Skills & Domains.
  - **Stage 5**: Flowing Torus manifold for Education & Experience.
  - **Stage 6**: Planar harmonic grid for GitHub & Open Source.
  - **Stage 7**: Convergent focal vortex leading into the Contact transmission section.
- **Responsiveness**: Responsive 12-column grid system, adapting cleanly to tablet (6-col) and mobile viewports with dynamically throttled particle density.
- **Accessibility**: Keyboard navigable skip links, visible focus states, ARIA roles, semantic landmarks, and full `prefers-reduced-motion` support.

## Running Locally

Because this is a pure static site with native browser APIs, you can run it with any standard HTTP server:

### Option 1: Python 3 (Recommended)
```bash
python3 -m http.server 8000
```
Then open: [http://localhost:8000](http://localhost:8000)

### Option 2: Node.js (npx serve or http-server)
```bash
npx serve .
# or
npx http-server -p 8000
```

### Option 3: Direct File Browser
You can open `index.html` directly in any modern browser (Chrome, Edge, Safari, Firefox).
